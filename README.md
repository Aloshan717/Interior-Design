# مصمم داخلي بالذكاء الاصطناعي

أداة شخصية لإعادة تصميم غرف منزلك: ترفع صوراً حقيقية للغرفة، يكتشف التطبيق ذوقك بصرياً، ثم يولّد تصميماً واقعياً **لنفس الغرفة** مع قائمة منتجات وأسعار تقديرية، وتعدّله بالكلام العادي.

```
صمّم ← شاهده على مكانك ← عدّله ← اعرف التكلفة ← اشترِ
```

> الاسم مؤقت. الـBranding معزول في `web/src/theme/brand.js`.

---

## النطاق

**استخدام شخصي.** لا حسابات، لا اشتراكات، لا App Store، لا مستخدمين آخرين. أنت المستخدم الوحيد.

| القرار | المعتمد |
|---|---|
| المنصة | تطبيق ويب (PWA) تضيفه لشاشة iPhone الرئيسية |
| الواجهة | React + Vite · عربي RTL بالكامل |
| التخزين | محلي على الجهاز أولاً، مع Supabase اختياري للمزامنة |
| توليد/تعديل الصور | Flux Kontext عبر fal.ai |
| حماية المفاتيح | دوال Vercel — لا مفتاح داخل المتصفح أبداً |
| iOS أصلي لاحقاً؟ | ممكن — الطبقات مفصولة بحيث تُستبدل الواجهة فقط |

**التكلفة المتوقعة:** ~$10 رصيد fal.ai (يكفي ~٢٠ غرفة) · Supabase مجاني · Vercel مجاني.

---

## التشغيل

```bash
cd web
npm install
npm run dev
```

يعمل فوراً بمزوّد ذكاء اصطناعي **تجريبي** (بدون مفاتيح، بدون تكلفة) لتجربة الرحلة كاملة.
لتفعيل التوليد الحقيقي: [`docs/08-api-keys-guide.md`](docs/08-api-keys-guide.md).
