# ٦ — الـWireframes

مواصفة كل شاشة. الشاشات مبنية فعلاً في `web/src/screens/` — هذه الوثيقة هي المرجع الذي بُنيت عليه.

**قواعد بصرية عامة (البند ٢٢):** خلفية `#F4F1EA` · نص `#24231F` · لكنة نحاسية `#8A6F4E` · حواف ١٦–٢٢px · ظلال خفيفة جداً · الصور كبيرة والفراغ سخي.

---

## ١ · الرئيسية

```
┌──────────────────────────────┐
│                     أهلاً بك │  ← نص صغير باهت
│           أعد تصميم مساحتك   │  ← 30px عريض
│ ارفع صور غرفتك ودع الذكاء    │
│ الاصطناعي يعيد تصميمها.      │
│                              │
│ ┌──────────────────────────┐ │
│ │    +  تصميم جديد         │ │  ← أسود، ٥٢px، عرض كامل
│ └──────────────────────────┘ │
│                              │
│                     مشاريعي  │        عرض الكل ←
│ ┌──────────┐  ┌──────────┐   │
│ │ [صورة]   │  │ [صورة]   │   │  ← شبكة ٢×٢، أحدث ٤
│ │ مكتمل    │  │ قيد التعديل│  │  ← شارة الحالة أعلى
│ │ الصالة   │  │ غرفة النوم│   │
│ │ اليوم    │  │ قبل ٣ أيام│   │
│ └──────────┘  └──────────┘   │
├──────────────────────────────┤
│  الرئيسية  مشاريعي  الإعدادات │  ← ٣ تبويبات فقط
└──────────────────────────────┘
```
**قرار:** الرئيسية تعرض ٤ مشاريع فقط. القائمة الكاملة في تبويب مستقل — لتبقى الرئيسية بسيطة.

## ٦ · التصورات — البندان ١٢ و١٣

```
│      تصورات مقترحة           │
│ اتجاهات مختلفة قريبة من ذوقك │
│ ┌──────────────────────────┐ │
│ │        [صورة 4:3]      ✓ │ │  ← كبيرة
│ └──────────────────────────┘ │
│ عصري دافئ              [🔍] │  ← 🔍 = ملء الشاشة
│ ┌──────────────────────────┐ │
│ │        [صورة 4:3]        │ │
│ └──────────────────────────┘ │
│ فخامة عصرية            [🔍] │
│         … ٤ تصورات           │
│ ┌──────────────────────────┐ │
│ │ ░░░ يُولَّد الآن ░░░       │ │  ← هيكل عظمي للقادم

## ٨ · التعديل — البند ١٨

```
┌──────────────────────────────┐
│ ←    التعديل  6/7   ▓▓▓▓▓▓░  │
│ ┌──────────────────────────┐ │
│ │   [التصميم الحالي]       │ │
│ └──────────────────────────┘ │
│              النسخ           │
│ [نسخة 3]✓ [نسخة 2] [نسخة 1] │  ← تمرير أفقي — البند ١٩
│ (الحالية) غيّر الثريا         │
│                              │
│ جرّب مثلاً                    │  ← يظهر قبل أول رسالة فقط
│ (غيّر الثريا)(خلّ الجدران أفتح)│
│ (أبي كنبة أكبر)(خلّ أفخم)     │
│                              │
│           ┌────────────────┐ │
│           │  غيّر الثريا   │ │  ← فقاعة المستخدم (يمين)
│           └────────────────┘ │
│ ┌────────────────┐           │
│ │ جاهز — عدّلت    │           │  ← فقاعة الرد (يسار)
│ │ الإنارة وأبقيت  │           │
│ │ بقية التصميم.   │           │
│ └────────────────┘           │
├──────────────────────────────┤
│ [ اكتب ما تريد تغييره… ] (➤) │  ← ثابت أسفل
└──────────────────────────────┘
```
**داخلياً:** الأمر يُصنَّف `بصري` → نموذج الصور، أو `تجاري` («بميزانية أقل») → محرّك المنتجات. المستخدم لا يرى هذا التمييز.

## ١٠ · مشاريعي — البند ٢١

شبكة ٢×٢ من بطاقات المشاريع، كل بطاقة: صورة الغلاف · شارة الحالة · الاسم · النوع · آخر تعديل · زر حذف. الضغط يفتح المشروع **على آخر خطوة وصلها**.

## ١١ · الإعدادات

`الذكاء الاصطناعي` (المزوّد الحالي + تنبيه) · `البيانات` (عدد المشاريع، المساحة، حذف الكل) · `عن التطبيق`.

```
│                              │

│            ◟◞                │
│      نبني التصورات…          │
│      قد يستغرق هذا لحظات     │
