# ٨ — دليل مفاتيح API

> **لا تحتاج شيئاً من هذا الآن.** التطبيق يعمل كاملاً بمزوّد تجريبي. اتبع هذا الدليل عندما تريد التوليد الحقيقي.

---

## ما هو المفتاح ولماذا لا يوضع في التطبيق؟

المفتاح نص مثل `fal_a1b2c3…` يقول للخدمة «احسب تكلفة هذا الطلب على حسابي».

**القاعدة الحديدية:** لا يوضع داخل كود المتصفح إطلاقاً. أي شخص يفتح صفحتك يستطيع قراءته من أدوات المطوّر واستنزاف رصيدك. المفتاح يعيش في **متغيرات بيئة الخادم** فقط — نفس النمط الذي استخدمته في `api/scan.js` في مشروع GAUGE.

---

## ما تحتاجه

| الغرض | الخدمة | التكلفة |
|---|---|---|
| توليد وتعديل صور التصميم | **fal.ai** (Flux Kontext) | ~$0.04 للصورة · ~$0.08 للجودة الأعلى |
| قراءة صور غرفتك + استنتاج الذوق + فهم أوامر التعديل | **Google AI Studio** | مجاني بحد يومي سخي |
| قاعدة البيانات (اختياري) | **Supabase** | مجاني |
| الاستضافة | **Vercel** | مجاني |

**التكلفة الواقعية:** الغرفة الواحدة (٤ تصورات + تصميم + ٤ تعديلات) ≈ **١٠ صور ≈ $0.45**.
رصيد **$10 يكفي ~٢٠ غرفة** — أكثر من بيت كامل.

## الخطوة ١ — مفتاح fal.ai

1. افتح `fal.ai` → **Sign up** بحساب Google
2. من القائمة الجانبية → **Keys** → **Add key**
3. انسخ المفتاح فوراً — لن يظهر مرة أخرى
4. **Billing** → أضف بطاقة → اشحن **$10**

> اضبط حد إنفاق شهرياً في صفحة Billing. طبقة حماية ثانية فوق سقف الطلبات في الكود.

## الخطوة ٢ — مفتاح Google AI Studio

1. افتح `aistudio.google.com`
2. **Get API key** → **Create API key**
3. انسخه

## الخطوة ٣ — النشر على Vercel

```bash
cd web
npx vercel
```

اتبع الأسئلة (اربطه بحساب GitHub). سيعطيك رابطاً مثل `https://your-app.vercel.app`.

## الخطوة ٤ — إضافة المفاتيح لـVercel

لوحة Vercel → مشروعك → **Settings** → **Environment Variables**:

| الاسم | القيمة | إلزامي |
|---|---|---|
| `FAL_KEY` | مفتاح fal.ai | ✅ |
| `GOOGLE_AI_KEY` | مفتاح Google AI Studio | ✅ |
| `VITE_AI_PROVIDER` | `fal` | ✅ |
| `FAL_EDIT_MODEL` | لتغيير نموذج التحرير عن الافتراضي | ❌ |
| `FAL_T2I_MODEL` | لتغيير نموذج التوليد النصي | ❌ |
| `VISION_MODEL` | لتغيير نموذج الرؤية | ❌ |

> `VITE_AI_PROVIDER=fal` هو المفتاح الذي يبدّل المزوّد. تركه فارغاً يبقيك على التجريبي.
> الثلاثة الاختيارية موجودة لأن أسماء النماذج تتغيّر مع الوقت — تُعدَّل من هنا بلا لمس الكود.

ثم **Redeploy**.

### حماية الرصيد
لا يوجد عدّاد يومي في الخادم — دالة Vercel بلا ذاكرة مشتركة بين الطلبات، فأي عدّاد فيها وهمي.
**الحماية الحقيقية في fal.ai نفسه:** صفحة Billing → اضبط حد إنفاق شهرياً. افعلها قبل أول تشغيل.

## الخطوة ٥ — إضافته لشاشة iPhone

افتح الرابط في **Safari** → زر المشاركة ↗ → **إضافة إلى الشاشة الرئيسية**.
يظهر بأيقونة ويفتح بملء الشاشة بلا شريط متصفح — تماماً كتطبيق.

## الكود جاهز بالكامل ✅

| الدالة | تعمل ماذا |
|---|---|
| `api/generate.js` | تبدأ مهام التصورات أو التصميم أو صور الذوق |
| `api/job/[id].js` | حالة المهمة، وتعيد الصورة مضمّنة عند اكتمالها |
| `api/edit.js` | التعديل الموضعي عبر Kontext |
| `api/analyze-space.js` | يقرأ صور غرفتك: النوافذ، الأبواب، الأرضية، الإضاءة — ويترجم رغباتك للإنجليزية |
| `api/parse-intent.js` | يفهم أمر التعديل العربي ويصنّفه بصرياً أو تجارياً |
| `api/_lib/prompts.js` | صياغة التعليمات — أهم ملف: هنا يُفرض الحفاظ على هندسة غرفتك |

**ما لم يُختبر بعد:** لا أستطيع الاتصال بـfal.ai من بيئتي، فالربط مكتوب ومُدقَّق نحوياً لكنه **لم يُشغَّل مرة واحدة**. توقّع جولة ضبط بعد أول تشغيل — غالباً في اسم النموذج أو شكل رده. أرسل لي أي رسالة خطأ تظهر وأصلحها فوراً.

## أول تشغيل — ماذا يحدث

١. تفتح شاشة **الذوق** أول مرة → يولّد التطبيق **١٢ صورة غرف واقعية** (~دقيقة، ~$0.5).
   تُحفظ على جهازك، فلا تتكرر التكلفة أبداً بعدها.
٢. تختار ٣ صور أو أكثر → يقرأ نموذج الرؤية صور غرفتك.
٣. **التصورات الأربعة تُبنى على صورة غرفتك أنت** — لا غرفة خيالية.
٤. التصميم النهائي ثم التعديلات، كلها تبني على الصورة السابقة.

**تكلفة الغرفة الواحدة:** ~١٠ صور ≈ **$0.45**.
