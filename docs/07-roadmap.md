## ⏭️ المرحلة ٢ — الذكاء الاصطناعي الحقيقي ← **التالية**

**الهدف:** الإجابة على سؤال الجودة.

| المهمة | التفصيل |
|---|---|
| حساب fal.ai ورصيد ~$10 | [دليل خطوة بخطوة](08-api-keys-guide.md) |
| نشر على Vercel | يشغّل دوال `/api` التي تحمي المفتاح |
| `/api/generate` + `/api/job/:id` | نمط المهمة في الخلفية |
| تفعيل `FalKontextProvider` | متغير بيئة واحد — لا شاشة تتغيّر |
| ضبط الـPrompt للحفاظ على الهندسة | أهم عمل في المرحلة كلها |
| تحليل الصور بنموذج رؤية | يغذّي التوليد بوصف المكان الحقيقي |
| سقف استهلاك يومي | يحميك من خطأ يستنزف الرصيد |

**نقطة القرار:** إن انزلقت هندسة الغرفة → نضيف طبقة ControlNet بخريطة العمق. البنية تسمح بذلك بدون إعادة كتابة.
